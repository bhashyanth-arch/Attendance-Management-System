# Attendance Management System

## Project Description

This project is a Python-based Attendance Management System developed as a mini project. It helps maintain student attendance records digitally and provides attendance analysis.

## Features

* Add multiple students
* Prevent duplicate student entries
* View student list
* Mark attendance (Present/Absent)
* Store attendance records with date
* View attendance reports
* Calculate attendance percentage
* Search student details

## Technologies Used

* Python
* File Handling
* Functions
* Loops
* Conditional Statements

## Files Used

* attendance.py
* students.txt
* attendance.txt

## How to Run

1. Install Python.
2. Open the project folder.
3. Run:
   python attendance.py
4. Use the menu options.
